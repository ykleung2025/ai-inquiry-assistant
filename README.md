# AI 科學探究助手（小五科學・點選版）

**課堂網址：** https://ykleung2025.github.io/ai-inquiry-assistant/

樂華天主教小學小五｜物質與變化——空氣的特性／大氣壓力。

學生開連結，喺首頁**二揀一**（覆杯，或紙盒凹陷）。全程按鈕、單選、多選，**唔使登入，唔使打字**。頁面冇呼叫任何聊天機械人 API，助手句子全部寫死。

做完其中一個活動就可以返選單。唔使兩個都做，亦唔使跟住全課時間表。

## 教學重點

完成**其中一個**活動後，學生能夠：

- 知道大氣有壓力，用「外面大氣壓力同內部壓力差」講自己揀嘅現象（覆杯**或**紙盒凹陷）。
- 先點選預測同理由，再按提示觀察，判斷時引用**至少一項**觀察做證據。
- 唔盲從助手，願意用觀察修正想法。

教師備課（學生畫面**唔會**標示邊個解釋先啱，亦唔會出「標準答案」）：

| 活動 | 想學生用證據靠近嘅講法 | 常見講法，留俾學生自己判斷 |
| --- | --- | --- |
| 覆杯 | 杯外大氣壓力向上托住卡紙，同杯內水向下等作用形成壓力差。唔好簡化成「只有大氣壓力」。 | 卡紙被水吸住。可用「漏水／杯口唔密合」嘅觀察對質。 |
| 紙盒凹陷 | 盒內壓力變低，外面大氣壓力把盒壓凹。同覆杯都係內外壓力差，但是獨立活動。 | 紙盒自己縮，或者被吸管吸力拉凹。 |

判斷屏的解釋 A／B **外觀一樣**，網頁唔會話邊個先係標準答案，亦冇分數。

## 點用（約一個活動，連實驗）

1. 首頁可選組號 1–12（撳數字，可唔填）。冇文字格。
2. 揀「覆杯實驗」或「紙盒飲品凹陷」。
3. 每個活動四屏，可以前後翻：
   - ① **我的預測**：預測＋理由，撳「記下預測」後**鎖定**，唔可以改原先選擇。
   - ② **助手追問**：固定一句追問，單選一項實驗時會留意嘅嘢。
   - ③ **我的觀察**：可多選具體現象，再單選同原先預測相同／唔同／部分相同。
   - ④ **判斷助手**：讀解釋 A、解釋 B，揀 A／B／兩個都唔完整；**至少勾一項來自③嘅證據**先可以交；再評助手整體，並揀一句出口句讀出嚟。
4. 「其他」只係選項。老師寫黑板，或同學口頭補一句。頁面**冇文字輸入框**。
5. 「選項紀錄」用呢部裝置嘅 localStorage 保存，可顯示、複製、下載文字檔。冇姓名，唔會上傳。

## 安全

膠杯唔用玻璃；托盤上方；紙盒活動唔飲用。每屏底部都有呢句提示。

## GitHub Pages

倉庫 Pages 用 **main 分支、根目錄 `/`**。課堂網址：

https://ykleung2025.github.io/ai-inquiry-assistant/

頁面要等呢次改動合併入 `main` 之後，先會喺上面個網址出現。合併前可以喺本機預覽。

## 檔案（放喺 repo 根目錄）

- `index.html`
- `styles.css`
- `app.js`

唔使安裝、唔使 build。樣式同腳本用相對路徑，專案頁同本機預覽都用得。

本機預覽：

```bash
python3 -m http.server 8080
```

然後開 http://localhost:8080/

## 私隱

選項紀錄只留喺該部瀏覽器。重新整理唔會消失；清除網站資料，或喺「選項紀錄」撳兩次「清除本機紀錄」，先會刪除。唔收集學生姓名。
